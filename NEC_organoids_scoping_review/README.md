# NEC intestinal organoids scoping review

Working project for the scoping review on intestinal organoid models of neonatal necrotizing enterocolitis (NEC).

## Current working files
- Audited second-draft manuscript (DOCX and PDF)
- Central extraction matrix v4 (XLSX)
- English study-selection flow and conceptual figures
- Consolidated working package (ZIP)

## Important note
Publisher-controlled full-text articles are not stored in this repository. The extraction matrix retains study identifiers and source traceability.
